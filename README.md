# DAKSH Raghav — Lab 3 Portfolio

## Files
- `index.html` — semantic portfolio structure and validated contact form.
- `style.css` — external stylesheet with Flexbox, Grid, responsive breakpoints, relative units, transitions and keyframe animations.

## Run
Open `index.html` in a browser. The Google Font is loaded from Google Fonts when an internet connection is available; the page falls back to a sans-serif font if it is not.

## Responsive checks
Test at approximately 375px (mobile), 768px (tablet), and 1366px (desktop).

## Contact form note
The form includes browser-side required-field, email-format and minimum-length validation. It is a front-end lab demonstration; actual message delivery requires a server-side endpoint or form service.
